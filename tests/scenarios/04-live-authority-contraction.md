# Live authority contraction

## Initial evidence

A Workflow Plan was built while code edits and merge were permitted. Before the next effect, Target Project instructions add a review gate, the credential loses write scope, and an optional provider becomes unavailable.

## Expected decision

Apply the instruction, permission, and credential contractions immediately. Treat provider absence as affecting only dependent work and not as Impossibility.

## Attempted effect

Revalidate current instructions, approvals, permissions, credentials, and capability availability before editing or merging.

## Native outcome

No stale-plan mutation or merge occurs. Work that does not need the missing write permission or provider continues, and native evidence records the review or access gate.

## Continuation or resumption

After review, restored access, a compatible local fallback, or explicit scope contraction, reread current controls and construct a new plan. Never reuse the old authority snapshot.
