Independent work can use available local repository surfaces. A plan also proposes an undeclared child Orchestrator whose Revision is unavailable; a later proposal would form a cyclic Orchestrator edge by repeating `ship` in the same branch.

## Expected decision

Use documented local behavior for the absent skill or tool when compatible, isolate provider- and Target Project-dependent work, and continue independent local work. Reject the unavailable, undeclared, incompatible, or cyclic Orchestrator edge because `Direct relationships` is `None`.

## Attempted effect

Discover available local capabilities and compatible native Target Tasks. Do not consult the Workbench Map, silently substitute a provider or Orchestrator, or expand authority.

## Native outcome

`ship` retains control. Available in-scope work progresses, while each skill, tool, provider, or Target Project dependency records its exact gate. No capital-D Orchestrator Delegation occurs.

## Continuation or resumption

Replan mutation through a compatible native Target Task and continue root read-only coordination. If Target Task dispatch is unavailable, suspend only dependent mutation without substituting direct root mutation. Resume provider-dependent work if the named capability returns; absence alone is not Impossible.
