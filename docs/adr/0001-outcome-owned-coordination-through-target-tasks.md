# Own outcomes through a coordination-only root and native Target Tasks

`ship` owns one bounded code-delivery outcome while its root Session remains coordination-only for Target Project mutation and routes every mutation through bounded native Target Tasks. This replaces the earlier dynamic direct-or-dispatch choice: task boundaries remain evidence-driven rather than fixed, while the root reconciles evidence, plans, dispatches, monitors, isolates blockers, verifies integration, prevents duplicates, and retains terminal accountability. Authorized root read-only investigation and orchestration-native evidence management preserve Continuation-First without turning task completion into an implementation handoff or introducing a registry, copied work graph, or one-task-per-item rule.
